# 🛠️ DevTools Hub

A comprehensive, open-source collection of developer tools for minifying, formatting, and optimizing code.


## ✨ Features

- **🚀 Multiple Tools** - CSS, JavaScript, HTML minifiers, JSON formatter, and more
- **🌓 Dark/Light Theme** - Automatic theme switching with persistent preference
- **📱 Fully Responsive** - Works on desktop, tablet, and mobile
- **🔒 Privacy First** - All processing happens client-side; no data is sent to servers
- **⚡ Fast & Lightweight** - Zero dependencies, optimized for performance

## 🛠️ Available Tools

| Tool | Description | Status |
|------|-------------|--------|
| **CSS Minifier** | Compress and optimize CSS code | ✅ Live |
| **JavaScript Minifier** | Minify JS for production | ✅ Live |
| **HTML Minifier** | Clean and compress HTML markup | 🚧 Coming Soon |
| **JSON Formatter** | Format and validate JSON data | 🚧 Coming Soon |
| **Color Converter** | Convert between HEX, RGB, HSL | 🚧 Coming Soon |
| **Regex Tester** | Test and debug regular expressions | 🚧 Coming Soon |


## 🚀 Getting Started

### Prerequisites

- Any modern web browser (Chrome, Firefox, Safari, Edge)
- (Optional) A local server for development

### Installation

#### Option 1: Direct Download

Clone the repository:
```bash
git clone https://github.com/zytherdev/devtools-hub.git
cd devtools-hub
```

#### Option 2: Local Development Server

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (http-server)
npx http-server

# Using VS Code Live Server
# Open with Live Server extension
```
