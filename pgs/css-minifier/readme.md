# ⚡ CSS Minifier

A lightweight, browser-based CSS minification tool that removes unnecessary characters from CSS code to reduce file size and improve loading performance. Built with vanilla JavaScript and a clean, responsive interface.


## ✨ Features

- **Real-time minification** - Paste your CSS and minify with one click
- **Character statistics** - See input/output character counts and savings percentage
- **Copy to clipboard** - One-click copy of minified output
- **Sample CSS** - Pre-loaded example to test the tool
- **Keyboard shortcut** - Press `Ctrl+Enter` (or `Cmd+Enter` on Mac) to minify
- **Smart minification** - Removes comments, whitespace, and unnecessary characters while preserving valid CSS
- **Responsive design** - Works on desktop and mobile devices
- **Zero dependencies** - Pure HTML, CSS, and JavaScript
