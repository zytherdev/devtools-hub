# ⚡ JS Minifier

A powerful, browser-based JavaScript minification tool that reduces JavaScript file size by removing comments, whitespace, and unnecessary characters. Built with vanilla JavaScript and a sleek dark theme interface.


## ✨ Features

- **Smart minification** - Removes comments, whitespace, and optimizes code
- **Boolean optimization** - Converts `true` to `!0` and `false` to `!1`
- **Real-time statistics** - See character savings and percentage reduction
- **One-click copy** - Copy minified code to clipboard instantly
- **Sample code** - Pre-loaded with practical JavaScript examples
- **Keyboard shortcut** - Press `Ctrl+Enter` (or `Cmd+Enter`) to minify
- **Zero dependencies** - Pure HTML, CSS, and JavaScript
- **Responsive design** - Works on desktop, tablet, and mobile
